# Redes e comunicação

---

Redes permitem a comunicação entre componentes de um sistema, como clientes, APIs, servidores, bancos de dados e serviços externos.

Em sistemas distribuídos, a comunicação pela rede introduz aspectos como:

- Latência
- Throughput
- Disponibilidade
- Confiabilidade
- Segurança
- Roteamento
- Protocolos de comunicação
- Gerenciamento de conexões

Uma comunicação entre cliente e servidor pode envolver várias camadas e protocolos:

```text
Client
   |
   v
DNS
   |
   v
TCP / UDP
   |
   v
TLS
   |
   v
HTTP
   |
   v
Server
```
