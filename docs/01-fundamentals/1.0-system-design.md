# System Design

> Definir como componentes de um software, dados e processos operacionais cooperam para satisfazer os requisitos de um produto sob condições realistas de carga e falhas.

---

## Falhas do sistema

- **Fault**: um componente que se desvia de sua especificação (indisponibilidade de disco, pausa em processos, request handler devolvendo dados corrompidos).
- **Failure**: o sistema como um todo deixa de fornecer o serviço ao usuário.

Tolerância a falhas (FAULT) não significa fingir que componentes nunca quebram. Significa definir quais falhas o sistema deve absorver antes de se tornarem falhas visíveis ao usuário.
